LIBRARY MANAGEMENT SYSTEM

ABOUT
This is a modern Library Management System designed to manage books, members, borrowing, and returns in a simple and efficient way.

FEATURES

Book Management:
- Add new books
- Update book details
- Delete books
- Search books by title, author, or category
- Track available and borrowed books

Member Management:
- Add new members
- Update member information
- View member details

Borrowing System:
- Borrow books
- Return books
- Track due dates
- View borrowing history

Dashboard:
- View total books
- View total members
- View active borrowings

Authentication:
- User login system
- Admin access control
- Secure password handling

TECHNOLOGIES USED
- Frontend: React.js, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT, bcryptjs

INSTALLATION

1. Clone the repository:
git clone https://github.com/your-username/library-management-system.git

2. Install backend:
cd backend
npm install

3. Install frontend:
cd frontend
npm install



5. Run backend:
npm run dev

6. Run frontend:
npm run dev
