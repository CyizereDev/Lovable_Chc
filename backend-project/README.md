# Backend (SMS) — MongoDB + Express

## Setup
1. Make sure MongoDB is running locally (mongodb://127.0.0.1:27017)
2. `npm install`
3. (Optional) Edit `.env` to change MONGO_URI
4. `npm run dev` → http://localhost:5000

The `SMS` database and collections (users, products, warehouses, stocktransactions) are created automatically on first insert.
